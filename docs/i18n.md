# Internacionalización y publicación editorial

Decisión base: ADR-0003 (rutas/slugs/SEO), ADR-0008 (traducciones). Alcance inicial acordado: **cinco idiomas** (`es`, `en`, `pt`, `fr`, `de`). Se pueden añadir más desde un **registro central** (`src/i18n/locales.ts`) sin duplicar componentes ni entidades.

## 1. Idiomas

| Código | Idioma                                      | Nombre en el selector | `lang` HTML | Notas                                                                                                                                                    |
| ------ | ------------------------------------------- | --------------------- | ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `es`   | Español (**predeterminado**, idioma fuente) | Español               | `es`        | Idioma original de contenidos y nombres oficiales                                                                                                        |
| `en`   | Inglés                                      | English               | `en`        |                                                                                                                                                          |
| `pt`   | Portugués                                   | Português             | `pt`        | Borrador de trabajo en **portugués brasileño** (el `Intl` genérico `pt` también usa convenciones brasileñas); variante a decidir por una persona (BR/PT) |
| `fr`   | Francés                                     | Français              | `fr`        |                                                                                                                                                          |
| `de`   | Alemán                                      | Deutsch               | `de`        | Textos largos: la UI se diseña con holgura                                                                                                               |

- El selector muestra **nombres de idioma en su propio idioma**; **no** usa banderas.
- **Idioma ≠ región ≠ moneda ≠ zona horaria.** El idioma de la interfaz no cambia la moneda ni las unidades.

## 2. Rutas

Prefijo de idioma **siempre** (`localePrefix: 'always'`). Rutas estructurales localizadas (`pathnames`, estático):

| Ruta interna           | `es`               | `en`                   | `pt`               | `fr`                   | `de`                 |
| ---------------------- | ------------------ | ---------------------- | ------------------ | ---------------------- | -------------------- |
| `/`                    | `/`                | `/`                    | `/`                | `/`                    | `/`                  |
| `/explore`             | `/explorar`        | `/explore`             | `/explorar`        | `/explorer`            | `/entdecken`         |
| `/destinations`        | `/destinos`        | `/destinations`        | `/destinos`        | `/destinations`        | `/reiseziele`        |
| `/destinations/[slug]` | `/destinos/[slug]` | `/destinations/[slug]` | `/destinos/[slug]` | `/destinations/[slug]` | `/reiseziele/[slug]` |
| `/sources`             | `/fuentes`         | `/sources`             | `/fontes`          | `/sources`             | `/quellen`           |
| `/accessibility`       | `/accesibilidad`   | `/accessibility`       | `/acessibilidade`  | `/accessibilite`       | `/barrierefreiheit`  |

Ejemplos del documento rector: `/es/explorar`, `/en/explore`, `/pt/explorar`, `/fr/explorer`, `/de/entdecken`.

**Slugs de destino** (parte dinámica): registro `destination_slugs(destination_id, locale, slug, is_current)`. Reglas:

1. La URL se resuelve a `destination_id` por `(locale, slug)`.
2. Un slug **anterior** del mismo idioma → **308** al slug actual.
3. Un slug de **otro idioma** (p. ej. `/en/destinations/<slug-es>`) → **308** al slug del idioma de la URL.
4. Slug desconocido → 404 localizado.
5. Cambiar un slug **conserva** el anterior como alias (nunca se borra).
6. Unicidad `(locale, slug)`; slugs en ASCII minúsculo con guiones, derivados con normalización NFD (los nombres oficiales con acento se conservan en el campo `name`).

### Idioma de una URL

1. **La URL explícita determina el idioma** de una página compartida.
2. Sin prefijo (`/`): preferencia guardada → `Accept-Language` → `es`.
3. **Sin geolocalización** para imponer idioma.
4. Cookie `NEXT_LOCALE`: **de sesión** por defecto; persistente solo si la revisión legal lo aprueba.

### Cambiar de idioma conserva el contexto

El selector reconstruye la URL de la **misma** vista en otro idioma: ruta localizada + `slug` del destino en el idioma objetivo + **todos los parámetros de estado** (cámara, capas, filtros, viaje activo). La URL es la fuente de verdad del estado, por lo que cambiar de idioma **no recrea** el mapa si no es necesario; si se recreó, se libera la instancia anterior y se restaura desde la URL. Hay prueba E2E.

## 3. Contenido y traducciones

Entidades **separadas** de sus traducciones (ADR-0008). Cada traducción editorial registra: `entity_id`, `locale`, campos traducidos, `slug` (si aplica), `source_language`, `source_version`, `translation_status`, `translated_at`, `reviewed_at`, `reviewed_by`, `provenance`.

| `translation_status` | Significado                                                      | ¿Indexable en producción?                                | ¿Visible?                             |
| -------------------- | ---------------------------------------------------------------- | -------------------------------------------------------- | ------------------------------------- |
| `draft`              | Borrador humano o de IA sin pasar a revisión                     | No                                                       | Solo editores                         |
| `machine_translated` | Producida por traducción automática; **nunca** se marca revisada | **No** (salvo contenido no sensible y bandera explícita) | Sí, con aviso «traducción automática» |
| `reviewed`           | Revisada por una persona con nombre y fecha                      | Sí si la política lo permite                             | Sí                                    |
| `published`          | Aprobada para publicar                                           | **Sí**                                                   | Sí                                    |
| `outdated`           | El original cambió (`source_version` superior)                   | No                                                       | Sí, con aviso de actualidad           |

**Categorías sensibles** (restricciones, seguridad, información legal) **exigen** `reviewed`/`published` por una persona; no existe bandera que lo anule.

**Si falta una traducción** se muestra el contenido original **con indicación clara** («Este contenido solo está disponible en español») y el fragmento lleva `lang="es"` (lectores de pantalla). **Nunca** se presenta una página en español como si estuviera traducida.

**No se anuncia un idioma como «completamente publicado»** mientras tenga huecos relevantes: el estado de publicación por idioma se calcula (no se escribe a mano).

### Estado actual de las traducciones de **interfaz**

| Idioma              | Estado                                                                   | Verificación técnica automática                 | Revisión humana |
| ------------------- | ------------------------------------------------------------------------ | ----------------------------------------------- | --------------- |
| `es`                | `draft` (texto fuente redactado con IA, pendiente de revisión editorial) | claves, ICU, marcadores                         | **Pendiente**   |
| `en` `pt` `fr` `de` | `machine_translated` (IA)                                                | claves, ICU, **paridad de marcadores** con `es` | **Pendiente**   |

Consecuencia: **ningún idioma es indexable en producción todavía**; en desarrollo y _staging_ todo es `noindex` (ver §6). Esto **no** impide probar la aplicación localmente.

## 4. Interfaz y formatos

- **Sin texto visible en componentes**: todo sale de `messages/<locale>.json` (mensajes **ICU**, interpolación segura, plurales). Una prueba analiza el AST de los `.tsx` y falla ante texto literal en JSX o en atributos `alt/aria-label/title/placeholder`.
- **Solo se carga el idioma activo** (el archivo de mensajes del locale actual).
- **Formatos con `Intl`**: números, fechas, horas, monedas, unidades, listas y tiempo relativo, mediante `src/i18n/format.ts`.
- **Zona horaria**: `America/Panama` para horarios y eventos locales (UTC−5 sin horario de verano); se distingue de la zona del visitante, que se muestra solo cuando es relevante.
- **Moneda y unidades**: preferencias **independientes** (`currency`, `unitSystem`), **no** se convierten ni cambian al cambiar de idioma. Moneda por defecto **USD**. [Pendiente] decisión editorial sobre mostrar PAB.
- **La marca no está en los mensajes**: los textos usan el marcador `{siteName}` alimentado desde `src/config/site.ts`, de modo que renombrar el producto no toca las traducciones.
- **Nombres oficiales, atribuciones y textos legales originales** se conservan en su idioma de origen cuando corresponde.
- **CSS con propiedades lógicas** y holgura para textos largos (alemán, francés, portugués). **No se afirma soporte RTL** hasta probarlo.
- **Controles de terceros** (MapLibre): se pasan las cadenas traducidas propias. Si un control externo no admite un idioma, se documenta aquí y se ofrece una instrucción accesible traducida; **no se falsea** su soporte.

## 5. Búsqueda multilingüe

Alias, nombres oficiales y sinónimos por idioma; normalización sin acentos y sin mayúsculas (`unaccent`, `pg_trgm`, `tsvector` con configuración por idioma y `simple` como respaldo). Un destino se encuentra por «Panama Canal», «Canal de Panamá», «Panamakanal», «Canal do Panamá» o «canal de panama». Los embeddings, si algún día se usan, deben admitir los cinco idiomas. (Fase 3/7.)

## 6. SEO

- `<html lang>` correcto y contenido público **renderizado en servidor**.
- Metadatos (título, descripción, Open Graph, textos alternativos) localizados con `generateMetadata`.
- **Canonical propio por versión idiomática válida**; **no** todos a español.
- **hreflang recíproco**, con **autorreferencia** y `x-default` (→ `/` en la home; → variante `es` en el resto), **solo** de variantes realmente publicadas.
- **Sitemap** con las variantes publicadas y sus alternates recíprocos.
- **No se indexan** páginas vacías, traducciones pendientes ni duplicados presentados como traducciones (`robots: noindex`).
- **Fuera de producción** (`SITE_ENV ≠ production`): `noindex, nofollow` global y `robots.txt` que deniega todo.

Política de publicación (código: `src/domains/editorial/publication.ts`):

```
indexable(entidad, locale) =
     SITE_ENV = production
  ∧ translation_status ∈ {published}                      // o reviewed, si la política del sitio lo declara
  ∧ campos requeridos completos
  ∧ ¬(categoría sensible ∧ ¬revisión humana)
```

## 7. IA, offline y administración

- La IA responde **en el idioma activo** y conserva la **procedencia original** de las fuentes; no traduce atribuciones ni citas literales.
- Los paquetes offline incluyen **contenido, interfaz y recursos del idioma elegido**.
- Administración y correos transaccionales que se implementen se internacionalizan igual.

## 8. Pruebas de i18n

| Prueba                | Qué detecta                                                 |
| --------------------- | ----------------------------------------------------------- |
| Paridad de claves     | Clave que falta o sobra en algún idioma                     |
| ICU válido            | Sintaxis de mensaje rota                                    |
| Paridad de marcadores | `{count}`/`{name}` distintos entre idiomas                  |
| Sin literales         | Texto fijo en componentes                                   |
| Rutas                 | Cada ruta localizada existe y responde 200 en los 5 idiomas |
| Slugs                 | Alias → 308; slug de otro idioma → 308; desconocido → 404   |
| hreflang/canonical    | Reciprocidad, autorreferencia, `x-default`, solo publicados |
| Fallback              | Falta traducción → original con aviso y `lang` correcto     |
| Contexto              | Cambio de idioma conserva destino/cámara/capas              |
| Accesibilidad         | axe en los 5 idiomas; foco y nombres accesibles             |
| Visual                | Textos largos en 5 idiomas, móvil y escritorio              |

## 9. Checklist de revisión humana (por idioma)

1. ¿Terminología turística y geográfica correcta (topónimos, exónimos)?
2. ¿Registro y tono coherentes? ¿Tuteo/ustedeo, _Sie/du_, _vous/tu_?
3. ¿Plurales y géneros correctos en las cadenas ICU?
4. ¿Longitud del texto compatible con el diseño?
5. ¿Alternativas textuales y etiquetas ARIA naturales para lector de pantalla?
6. ¿Cadenas legales/seguridad revisadas por persona competente?
7. Registrar `reviewed_by` y fecha; solo entonces `reviewed`.
